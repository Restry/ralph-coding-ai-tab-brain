## Codebase Patterns
- Use ES module imports in service worker (type: module in manifest)
- manifest.json at repo root, all extension files at root level
- lib/ directory for reusable modules: ai.js, grouper.js, tracker.js, knowledge.js, tabs.js
- Permissions: tabs, tabGroups, sidePanel, storage, activeTab
- Quality checks: `node --check <file>` for syntax, `node -e "JSON.parse(...)"` for manifest
- Chrome Tab Group valid colors: grey, blue, red, yellow, green, pink, purple, cyan, orange
- chrome.storage.sync keys: apiKey, apiEndpoint, model (set by options page)
- Default API endpoint: https://api.anthropic.com, default model: claude-sonnet-4-20250514
- lib/ai.js exports sendMessage(systemPrompt, userMessage) → returns response text string
- AI client uses anthropic-version: 2023-06-01, max_tokens: 1024
- AI client has 10s timeout via AbortController
- lib/tabs.js exports getAllTabs() → returns array of {index, tabId, title, url, domain, favIconUrl, pinned, windowId}
- Domain extraction: new URL(url).hostname, handles data: URLs and invalid URLs gracefully
- lib/grouper.js exports groupTabsWithAI(tabs) → returns {groups, totalGrouped, skipped}
- AI prompt instructs JSON-only response; parseAIResponse() strips markdown fences and validates
- chrome.tabs.group({tabIds}) returns a groupId, then chrome.tabGroups.update(groupId, {title, color})
- After AI call, re-query chrome.tabs.query({}) to catch tabs closed/opened during the request
- chrome.runtime.onMessage.addListener must return true for async responses (keeps message channel open)
- chrome.sidePanel.setPanelBehavior({ openPanelOnActionClick: true }) goes in onInstalled listener
- chrome.tabGroups.query({}) returns all existing tab groups
- Unassigned non-pinned tabs go to a 'Misc' group (grey color)
- lib/grouper.js exports groupTabsByDomain(tabs) for offline domain-based grouping
- lib/grouper.js exports groupTabs() as the main public API (AI first, domain fallback)
- Domain grouping color rotation: blue, green, cyan, orange, purple, pink, red, yellow
- eTLD+1 extraction: handle multi-part TLDs (co.uk, com.au) via KNOWN_SLDS set
- IndexedDB database name: 'TabBrainDB', object store: 'entries', keyPath: 'url'
- IndexedDB indexes: domain, lastSeen, archived (url is keyPath so implicitly unique)
- lib/knowledge.js exports: saveEntry, getEntry, updateEntry, getAllEntries, searchEntries, pruneOldEntries
- lib/tracker.js exports initTracker() — call in onInstalled and onStartup to register tab listeners
- Tab focus tracking: store { tabId, timestamp } in currentFocus, compute duration on next onActivated
- Auto-prune: 90 days max age, runs on initTracker()
- sidepanel.js is NOT an ES module — loaded via <script src> tag, no type=module
- chrome.runtime.sendMessage returns a Promise in MV3, can be awaited directly
- Side panel status messages use CSS class toggling: loading/success/error
- Side panel communicates with service worker via { action: 'actionName' } message shape
- Stale tab detection: compare tab's lastSeen in IndexedDB with Date.now(), threshold is 3 days
- Tabs without IndexedDB entries are treated as non-stale (not tracked long enough)
- service-worker.js handles getStaleTabs, archiveTab, archiveAllStaleTabs message actions
- Archive action: update/save entry with archived:true in IndexedDB, then chrome.tabs.remove(tabId)
